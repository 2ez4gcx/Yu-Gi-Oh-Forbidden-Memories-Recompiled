# Cyberse Blue-Eyes

This mod is intentionally inactive on the currently installed game build.
That build's HD type asset path is keyed only by the shared retail type name
(`dragon.png`), so using it would replace the icon on *every* Dragon card.

The included Cyberse icon is retained as source artwork for a build that has
the custom card-type runtime and a per-custom-type icon renderer.  Such a
build can give Blue-Eyes the Cyberse type and icon without changing any other
Dragon.
